# African Ranked: GA4 integration release gates (13 November 2026)

Google Search Console is connected, but GA4 is a separate property. The connected GSC Wizard account has no Google Analytics scope. The user's exact GA4 web stream measurement ID is not established, so do not guess it.

This release is disabled by default. GA4 loads only when all three Railway WEB variables are configured: GA4_MEASUREMENT_ID (verified G- ID), GA4_PRIVACY_NOTICE_APPROVED=true (owner-approved public privacy-policy page already published at /pages/privacy-policy), and GA4_ENABLED=true. Do not set these values on worker or scheduler.

A visitor sees a consent banner before any Google analytics network request. Rejecting never loads the tag; accepting loads gtag.js and sends the initial page_view. A footer button lets readers re-open the decision. On withdrawing consent after loading, the page reloads; no Google requests are initiated on later denied visits. Cookies set before withdrawal may persist until their normal lifetime unless cleared separately.

Release checklist:
- Verify Google Analytics Admin > Data streams > Web > Measurement ID, the domain and correct property.
- Publish a correct privacy notice identifying operator, contact details, cookies, Google Analytics, processors and retention practices. Obtain owner/legal approval first.
- Configure the three web environment variables through Railway, deploy, and check both browser consent paths using a new private-browser session.
- Verify no Google analytics requests before consent; after acceptance, confirm one page_view in GA4 Realtime and Google Tag Assistant. No duplicate tags.
- Verify the policy link works and the reject/change-preference workflow on mobile.
- This implements basic opt-in consent, not advanced cookieless pings. Google Ads personalization is always denied. Never claim analytics is connected until Realtime shows actual events.
